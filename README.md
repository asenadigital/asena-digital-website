# Asena Digital Website

A customized corporate website for Asena Digital, built with Astro 7 and Tailwind CSS.

## Brand and content

- Domain: https://asena.digital
- Primary language: English
- Turkish landing page: `/tr`
- Contact: main@asena.digital
- Brand palette: charcoal, black, silver and white
- Services: website development, custom software, e-commerce, mobile applications, AI & automation, and technology consulting

## Local development

Requirements: Node.js 22.12+.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The project is configured for deployment with the Astro Vercel adapter. Connect the project to a Vercel deployment, then add `asena.digital` and `www.asena.digital` in the hosting dashboard and configure the DNS records it provides.

## Contact form

The project enquiry form opens the visitor's default email application and prepares a message addressed to `main@asena.digital`. It does not transmit form data to a third-party service or website endpoint.
